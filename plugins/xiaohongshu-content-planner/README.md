# FIBOO 小红书内容策划

版本：0.3.2；基于原内容策划技能 0.3.1 的 FIBOO 市场分发适配。保留参考分析、产品事实校验、只读策划 HTML、用户确认、真实请求记录与生成后文件/尺寸检查。

## 配套插件与运行前准备

| 插件 | 何时使用 |
|---|---|
| `fiboo-product-materials` | 实时获取 FIBOO 产品事实、文档和主图；它还需要 `dingtalk-cli` |
| `dingtalk-cli` | 用员工钉钉账号读取公司产品资料；登录和资料库权限由员工本人完成 |
| `xiaohongshu-note-fetch` | 用户提供小红书链接，需要读取正文、按顺序取得原图时 |
| `kimi-webbridge` | 参考链接需要访问员工已登录浏览器，或需交互读取页面时；须按该插件说明连接浏览器扩展 |
| `wave-image` | 策划确认后生成或编辑图片时；须按该插件说明配置员工可用的服务凭据 |

本插件的原生依赖声明会安装以上五个配套插件；每项能力的登录、浏览器连接和服务配置仍按实际使用需要完成。只用本地附件策划时，无需调用这些外部服务。不能把“安装成功”当成钉钉已授权、浏览器已连接或生图凭据有效。

Python 脚本需要 Python 3.10 或更新版本，其运行逻辑仅使用标准库。实际调用脚本时，先确定当前 `SKILL.md` 的安装位置，再用脚本绝对路径；所有业务资料和输出放在任务目录，不写入插件缓存。

## 使用

例如：“为 fiboo 某产品，参考这篇小红书链接，做一篇五页内容。先给我看策划 HTML。”

技能先取得并核实产品与参考素材，再生成只读策划 HTML。确认对应版本后调用 `wave-image`，产物经过真实文件类型、数量及尺寸检查后交付人工审稿。技术检查不等于图片内容审核；本插件不自动发布笔记。

已有同名裸 Skill 时，应在确认市场版本能加载后停用旧的同名版本，避免混用 0.3.0、0.3.1 和市场版本。更新由市场分发管理；用户的业务材料与历史策划保留在各自任务目录。

## 验证

在插件根目录执行 `python -B -m unittest discover -s skills/xiaohongshu-content-planner/tests -p "test_*.py"`。这些离线测试使用合成资料，不调用生图、不执行发布、不构成真实业务验收。
