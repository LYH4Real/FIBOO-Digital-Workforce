# 参考驱动的视觉与提示词方法

制作分镜、选择参考图或编写生图提示词时读取。工具参数与尺寸执行遵循 [生图工作流](image-workflow.md)；参考范围沿用 [四维参考合同](reference-analysis.md)，不要重新要求用户确认已经说清楚的选择。用户提供过参考图文时，每个待生成页都必须传入原帖参考图，不允许只传目标产品图。

## 1. 先决定学什么，不先套风格词

把本页任务说清楚：让读者看到什么、理解什么，以及产品在本页是主体、例子、背景还是不出现。再按已确认的叙事、逐页构图、图片风格与文案语气四个维度选择视觉路线：

| 路线 | 应具体约束 | 不要自动引入 |
|---|---|---|
| 生活实拍／使用记录 | 真实物件、手持动作、机位、日常光线、使用状态，文字像后期加上的标注 | 棚拍布光、同色系精致道具、悬浮产品、奶油或水果装饰 |
| 生活照片＋轻拼贴 | 主照片与小照片的数量、位置、裁切、描边和各自叙事功能 | 将生活照片全部替换成抽象图标，或把拼贴简化成白底产品卡 |
| 科普信息图／清单／问答 | 标题层级、阅读顺序、表格或卡片结构、图文比例、标注依据 | 强行加入手持大产品、生活噪点、素人自拍或每页产品露出 |
| 明确要求的品牌视觉 | 按任务约定的视觉规范和商业用途设计 | 把“素人感”设为所有任务的默认审美 |

“粉色、干净、有质感、小红书风、素人感”不能单独构成提示词。把它们译成可观察的决定，例如“桌面有细小划痕、右手从画面右下握住杯子、普通窗光从左侧照入、背景仍可辨认”。这些是视觉方向，不是该图片已真实拍摄或有人真实使用过的证据。

仅参考配色，就只继承配色；仅参考机位，就不顺带继承原帖人物、症状、产品占比或全文版式。严格视觉替换要高度还原已确认的画面骨架和拍摄状态，但仍用目标产品、事实和新文案，不把原品牌、人物身份或原文一起复制。

## 2. 每页建立实际参考图映射

实际逐张看图，记录看到的内容，再选择要传给本页的图。路径必须由真实文件解析得到，在 MCP 所在机器可读；不能只在文字里说“参考原图”，调用时却只传产品图。只要任务收到过参考图文，每个待生成页的映射表第一类图片必须包含对应或最接近的原帖参考图。

| 传入序号／路径 | 来源及页码 | 本页角色 | 允许继承的可见特征 | 不继承／冲突处理 |
|---|---|---|---|---|
| 图1／已核对的绝对路径 | 原笔记第几页 | 结构或指定特点 | 如左侧三个圆形照片、右侧手持主体、上方标题 | 原文、原品牌、人物身份及未选择维度不继承 |
| 图2／已核对的绝对路径 | 当前产品素材 | 包装或实物外观 | 真实轮廓、长宽比、标识方向、材质 | 不据此推导功效、尺寸数字或认证 |
| 图3／已核对的绝对路径 | 当前产品素材 | 配件／质地／使用状态 | 勺形、粉面、盖子、杯壁或其他本页必要细节 | 原结构图里的竞品配件不能优先于本品 |
| 图4／已核对的绝对路径 | 已采用成图或场景素材 | 连续性 | 同一桌面、物件、人物特征或字体系统 | 旧图错误和过期文案不继承 |

表格只列本页实际需要且已获得的图，不固定要求四张。`image_paths` 的顺序必须与提示词中的“图1、图2……”逐项对应；发送前核对文件存在、图片确实可读以及角色没有错位。同一路径可承担多个明确角色，但不要用模糊的“以上图片均供参考”让模型自行竞争。

参考强度必须落到提示词：

- `【参考强度】严格参考`：还原已确认的元素数量、位置、比例、机位、裁切、文字层级、光线和质感；逐项写出，不只写“1:1复刻”。
- `【参考强度】中度参考`：保留选定的构图骨架或风格系统，允许围绕目标产品重新组织未指定部分。
- `【参考强度】轻度参考`：原图仍进入请求，只用于已说明的生活语境、光线、材质或叙事氛围；明确不复制布局、人物和原产品。

若参考只有链接而图片尚未落为本机可读文件，暂停依赖它的生图。不能用“链接已经看过”替代 `image_paths` 中的真实原图路径。

冲突按约束类型解决：

- 产品外观以相应规格的真实产品素材为依据；结构图负责构图，不负责重造产品。杯型、罐型不同而无法照搬位置时，保留页面功能并调整布局。
- 页面事实与指定文字以当前任务有效产品资料及用户确认稿为准；参考帖、历史好图和旧提示词中的数据、名称、卖点不能覆盖它们。当前对外名与旧包装字样可以分别适用，不擅自把实物包装改成新名称。
- 未获授权的可识别人物身份、签名、作者头像、专属插画、品牌视觉标识和整段原文不原样搬入新作品；可保留手持角度、空间关系等获选方法，重新创作画面。不得生成“原作者正在使用本品”的假象。
- 原图缺失时，暂停依赖其构图或质感还原的该页，不装作看过。仍可完成已获得资料支持的文案和其他页；若用户同意改为自主设计，明确标注不再声称参考还原。

## 3. 把“像原帖”拆成可执行的观察

对本次选定维度写一份短视觉蓝图。只描述看过的图；比例是本图的大致布局估计，不是平台要求。

1. **画面骨架**：全屏单张照片、几张拼贴或几行几列卡片；墙面与桌面分界；标题、主物件和留白各在哪里。用“上方约四分之一”“左下前景”代替“合理布局”。
2. **主体关系**：物件数量、大小关系、遮挡与画外裁切、左右手、抓握位置、盖子/工具状态。产品是放着、拿着、刚打开还是正在使用？避免一个物件在文字里同时要求完整露出又裁去一半。
3. **机位与光线**：俯拍、平视或近距离斜拍；焦点在哪；光从哪来；背景清楚还是略虚。生活实拍不默认大光圈、磨皮或轮廓光。
4. **真实细节**：挑选与动作相符的少量细节，如桌面细纹、杯壁水迹、粉面细粒、封膜撕开痕迹、手指受力。不是每页塞满脏乱、裂纹和噪点，也不凭空增加不存在的配件。
5. **加字方式**：标题在哪、是否描边、正文是底条还是裸字、箭头指向谁。照片加字与科普信息图分别处理，不把所有正文做成大广告口号。

特别检查“换品之后容易错”的物理约束：开罐后的盖子不能同时仍封在罐上；量勺有支撑或被手拿住，不能悬浮；平勺不能变成冒尖勺；杯/罐/手的比例应可信；反光、阴影和透视要一致。真实状态来自本品素材，不来自原竞品图的推断。

### 要求素人感时：把商业完美当作负面约束

先以语义清单记录的原帖特征为准，再补充手机随拍约束。素人感不是统一的暖色调、胶片滤镜或“高级生活方式”，而是画面像一个人在真实场景里顺手拍下：

- 使用普通手机的近距离广角或主摄视角，允许轻微透视、不完全水平、略偏的主体和非对称留白；不使用棚拍长焦压缩、完美轴对称或产品英雄位。
- 光线服从场景：窗光不均、室内顶灯混光或轻微直闪均可；允许局部高光、轻微阴影压住、有限噪点和非关键区域略虚。禁止轮廓光、商业渐变、均匀柔光箱和过度磨皮。
- 环境保留少量与动作有关的生活痕迹，如随手放置的杯子、折痕、桌面小划痕、开封痕迹；画面可以略乱但不能脏到影响产品识别。不要用整齐同色系道具、花束、水果阵列或悬浮装饰把它重新变成广告。
- 产品不必每页出现，也不必每次居中放大。产品作为使用物时允许被手或前景局部遮挡；包装关键识别信息仍须准确。整组产品露出页数服从策划，不因生图方便变成每页产品海报。
- 后期文字像用户加的笔记标注：少量、位置自然、允许轻微不齐；不能堆满统一品牌字卡、促销角标和大面积卖点徽章。

提示词同时写出正向特征和广告感禁用项，策划中保留 `ugc_required: true`，供人工审稿或用户明确要求的专项评估使用；该字段不触发自动审图。不能靠一句“真实素人感”代替这些可观察要求。

## 4. 将已确认文案分配到图片，而不是整篇塞进去

- 每页先确定一个主要信息，再给标题、补充说明与必要标注安排空间；密集表格可以承载多个并列项，但层级必须分明。
- 逐字列出本页允许出现的文字与位置，并区分“后期叠加文案”和“实物包装原有字样”。不得为了版面自动缩写标准表达、删单位、改数值或改用户定稿。
- 手机大小预览无法读清时，优先精简尚未定稿的说明或建议拆页；已确认长文不能悄悄改。必须保留的密集文字可改为“生成无字底图＋排版工具加字”，并交付实际排版结果后再验收，不能假称底图已有文字。
- 不凭空加入页码、认证、研究来源、作者署名、卖点标签或话题。示意图也不能伪装成真实标签、实验结果或证明材料。

## 5. 逐页自包含的提示词

提示词应让工具仅看到这一条与本页附件，也知道要做什么。提交前展开所有占位项；实际请求中的 `size` 另按生图工作流填写，文字写“3:4”不能替代参数。

```text
【输出】
生成本组第[页码]页：[页面任务]。[真实摄影/照片拼贴/信息图等路线]。
输出[实际宽]×[实际高]像素，[实际比例]；与本次请求 size 一致。

【参考强度】
[严格参考 / 中度参考 / 轻度参考]。具体只继承[逐页构图/图片风格/局部视觉特点]，不继承[品牌、人物身份、事实、原文等]。

【本页参考图：严格对应 image_paths 顺序】
图1：[绝对路径]。只继承[已确认维度和具体特征]；不继承[身份、品牌、文字等]。
图2：[绝对路径]。用于[当前产品外观或必要物件]，保留[看见的关键特征]。
[只列实际传入的其他图；产品事实和文案以以下明确指令为准。]

【整组锚点】
[本页必须保持的场景、物件、光线、画面文字系统和连续状态，完整写出。]

【本页视觉蓝图】
[区域位置、元素数量、机位、主体比例关系、动作、裁切和留白。]
[适用时写自然材质和使用痕迹；信息图则写卡片/表格/插图结构。]

【准确文字】
[逐条列出文字与位置；无字页明确不添加叠加文字。]
只出现上述叠加文案及确实可见的包装原有字样，不追加宣传语。

【保持与禁止】
[产品还原边界、明确不继承的参考元素、容易生成错的物理状态及本页禁用内容。]
```

不要写“风格同上”“参考上一页”“正文沿用策划案”而省略内容。也不要只写“高度还原”而不列可观察约束。长提示词的价值在具体控制，不在反复堆叠“高级、真实、精美”。删除互相冲突的描述及与本页无关的禁用项。

### 多页连续性与并行选择

- **可并行**：参考图全部已存在，对精确同人同景没有硬性要求。把同一套风格锚点分别写入每条提示词，每页独立传图。文字锚点有助一致性，但不保证严格相同的人物和空间。
- **需要先导页**：用户要求同一人物、同一桌面或精确视觉系统时，先生成并选定一张锚点页，再把这张实际存在的成图作为后续连续性参考。不要为了并行省掉用户要求，也不能把尚未生成的文件写入参考路径。
- 旧成图只继承已核对正确的特征。若它有镜像、错误包装或旧文字，优先更换参考或限定其继承范围，不能沿整组放大错误。

## 6. 两个完整的产品无关示例

以下是假设素材已核对后的写法示范，不是当前任务可直接调用的真实文件或产品事实。执行真实任务时替换为实际看过、可访问的素材与确认文字，不能照抄示例路径。示例尺寸仅演示与请求一致，并不代表所有工具都支持该值。

### 示例 A：参考生活开盖图，重新创作杯子使用页

前提：用户只借鉴俯拍与上下文字区；目标为用户提供的无品牌白色带盖随行杯。已查看的本品图确实有浅灰杯盖、透明杯口和杯壁水迹，无吸管。本页不声称任何人已经真实使用或推荐它。

```text
【输出】
制作一张1248×1664像素、3:4竖版的日常杯子开盖示意图，照片上轻量加字。它是生成的视觉稿，不制作使用者证言。

【参考强度】
中度参考。保留图1的斜俯拍、上下文字区和日常光线，不复制原杯型、人物身份或原文。

【参考图角色】
图1，<task>/参考/开盖构图.jpg：只借鉴斜俯拍机位、杯体居中偏下、上方标题和右下小字的位置；不复制原图杯子、配件、原文或人物身份。
图2，<task>/本品/正面.jpg：还原这只无品牌白色随行杯的轮廓、真实宽高比例与浅灰杯盖；不添加标识。
图3，<task>/本品/开盖.jpg：还原透明杯口、盖子打开后的内部结构和轻微杯壁水迹；不生成吸管或额外工具。

【整组锚点】
浅木色普通桌面、浅灰白背景、左侧自然窗光，阴影方向一致。物件是同一只白色杯子和浅灰杯盖。深灰粗体标题、白色窄底条正文。手机记录质感，背景仍可辨认，不采用产品棚拍的光晕和轮廓光。

【本页视觉蓝图】
手机从上方略向前斜拍，杯子位于画面中央偏下，整体占约一半画面高度；镜头可以看到透明杯口。浅灰杯盖放在杯子右上方桌面，盖子与杯口分离，不生成悬空盖子。杯中只保留少量清水，不添加水果或饮品颜色。桌面有细微木纹，杯壁保留图3所见的少量水迹；不要刻意铺满水渍。顶部留出约四分之一画面用于标题；右下留出短提示空间，不覆盖杯口。

【准确文字】
顶部标题：“开盖后，里面是什么样？”
标题下一行白底小字：“杯口、杯盖和内部结构，分开看清楚”
右下白底短句：“具体以收到的实物为准”
只出现这些文字，不增加容量、材质认证、使用体验或品牌。

【保持与禁止】
以图2、图3还原本品外观；若图1的杯型不同，调整杯子留白，不强行改造本品。禁止吸管、打泡器、悬浮杯盖、花束、商业渐变背景与新品宣传标。不要出现人物身份、顾客评价或所谓实测数据。
```

### 示例 B：只参考四格问答结构，做无品牌资料核对卡

前提：用户选择信息图形式，未要求真人或具体产品露出；本页讲阅读产品资料的方法，不生成假标签截图。

```text
【输出】
制作一张1248×1664像素、3:4竖版的产品资料核对卡。路线是清晰的信息图，不是生活照片或产品海报。

【参考强度】
中度参考。只保留图1的四格阅读骨架，不继承其配色、品牌、插图造型或原句。

【参考图角色】
图1，<task>/参考/四格问答.jpg：仅参考顶部标题、2列×2行卡片、底部总结的阅读结构。不要继承原图配色、品牌、作者署名、图标造型或任何原句。

【整组锚点】
暖白背景、深墨色文字、低饱和绿色小标题；统一圆角卡片和简洁线性图标。没有产品主视觉，没有人物或拍照质感。卡片内部留白一致，正文大到手机预览可以直接读清。

【本页视觉蓝图】
顶部约五分之一放一行主标题和一行说明。中部四张等宽卡片按左上、右上、左下、右下顺序阅读；每张卡片左上放序号，下面是小标题、两行短说明。图标分别为文件、标签页、日历和对话框，只用于辅助，不带数字或文字。底部是一条简洁总结栏，不增加署名和页码。没有实物标签截图，不把通用图标画成产品认证章。

【准确文字】
主标题：“看产品资料，先核对这4处”
副标题：“先确认信息适用范围，再开始写内容”
左上：“1  来源”／“这条信息来自哪份资料？”／“不要只看转述。”
右上：“2  规格”／“对应哪个型号或版本？”／“相似名称也要分清。”
左下：“3  时间”／“这份资料什么时候更新？”／“旧称不一定仍适用。”
右下：“4  确认状态”／“哪些已经确认，哪些待核对？”／“不要把草稿当定稿。”
底部：“来源、规格、时间、状态，一起看。”
斜线只表示此处列举的换行，不作为画面符号生成。

【保持与禁止】
```

## 7. 人工审稿或专项评估时：对照原参考、提示词与成图

默认生成后按[生图工作流](image-workflow.md)完成文件、格式、数量与尺寸检查后即交付人工审稿，不自动执行本节，不启动独立 Agent/视觉工具，不制作审查裁剪或放大图，不评分或视觉自动重试。以下要点供用户人工审稿使用；只有用户明确要求专项审图时才由独立评估方按[专项评估合同](workflow-gates.md#6-可选专项独立视觉评估与有限重试)执行。

审核时把每页成图与本页视觉蓝图、实际参考、指定文字对照：

- 用户要保留的特点是否出现？三张生活拼贴是否仍为三张，手持是否变成了静物，科普是否变成了广告？只要求配色时，不因布局不同判失败。
- 本品外观、真实物件、动作与物理状态是否正确？是否多出摇摇杯、搅拌器、配件或错色质地？
- 本页文字是否准确、可读，且没有把旧参考事实、绝对口感、功效或认证带回来？
- 多页约定的场景、人物、杯子或字体是否连续？重点页与纯科普页是否按约定控制产品露出？
- 生成质感是否符合这次选择，而不只是“粉色很统一”？

收到具体修改意见并有返工授权后定向修正，例如“恢复左侧三圆拼贴与右侧手持结构”“将冒尖粉面改为已确认的平勺状态”，不只说“更真实一点”。请求记录保留本页提示词、参考图及角色、参考强度、尺寸、输出与审核状态；实际像素检查和重试边界按生图工作流执行。用户提供过参考但实际请求未包含原帖参考图，该页直接失败；没有生成或没有实际审核的图不得标注已验收。人工待审状态不阻塞图片交付，也不代表内容、合规或发布通过。
