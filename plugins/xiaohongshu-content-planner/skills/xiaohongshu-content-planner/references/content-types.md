# 内容类型规则

标题、正文和图片文字的写作与改稿方法见 [自然文案方法](copywriting-method.md)。这里决定各类型的信息重点，不规定所有稿件采用相同篇幅和模板。

食品健康类同时应用 [食品与平台表达规范](food-platform-rules.md)。不同内容形式都不改变产品资质和广告责任；好物分享不豁免功效/代言限制，科普也不能成为变相保健食品广告。

## 好物分享

目标是用具体生活场景呈现选择过程和使用方式，而不是集中罗列产品卖点。

- 明确发布主体及有依据的情境；时间、地点只在真实材料提供且有用时写入，不为补齐“人设”而编造。
- 产品出现前先交代真实问题和选择标准。
- 体验描述必须来自用户提供的真实信息；没有真实体验时使用计划、观察或客观描述。
- 不捏造使用后的效果叙事。
- 当任务选定随手记录形式时采用相应真实感；视觉风格服从用户确认的参考范围，产品外观保持准确。

## 选购

目标是帮助用户建立选择标准，并说明产品为什么符合部分标准。

- 先给出可验证的选择维度，再介绍产品。
- 选择维度不能为某产品量身定制到失去普遍性。
- 对比参数时核对单位、规格、计量基准和适用人群；食饮类区分每 100g、每份和每日需求等口径。
- 不以“大牌、进口、专利”等无法核实的信息代替产品事实。
- 对比多个产品时必须分别读取对应产品资料。

## 科普

目标是提供可信的一般知识。是否可以介绍产品场景，先按产品身份、商业性质和渠道规则判断；不默认每篇科普都植入产品。

- 区分类别知识、个体建议和产品信息；健康类任务尤其注意一般营养知识的适用范围。
- 医疗、疾病、用药、痘肌、减重或特殊人群内容需要更严格审核。
- 数据、研究和强结论需要可查证来源；无法确认时标记缺口并移除未证实结论，不能只加“可能”就保留。
- 不用 emoji、谐音词或拆字规避本应遵守的合规要求。
- 产品植入只能使用已确认事实，不能从科普结论推导产品功效。

## 结构参考原则

- 按 [参考图文规则](reference-analysis.md) 确定沿用哪些维度；仅参考局部时不默认沿用整篇。
- 整体结构迁移可沿用页数、信息层级和叙事功能，产品事实与文案重新匹配，不能只是替换品牌名。
- 参考人物、效果或生活经历不能自动变成用户本人的真实经历。
- 用户已确定形式时尊重该选择；上述三类是常见分支，不限制其他创作形式。
