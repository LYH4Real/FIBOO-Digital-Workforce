# 方法依据与适用范围

核验日期：2026-09-07。用于说明本版方法的来源及局限；不是平台规则全集，也不是具体产品的发布许可。涉及投放、特殊品类或发布时，仍应核对当时的官方规则和产品资质。

## 已核验的一手材料

- [Digital.gov：Write for the reader](https://digital.gov/guides/plain-language/principles/write-for-reader)：从读者实际问题、需要和语境组织内容。用于本 Skill 的创作卡与阅读动机；迁移到中文社交内容是编辑方法判断，不代表已验证小红书流量提升。
- [Digital.gov：Clear and short](https://digital.gov/guides/plain-language/writing/clear-short)：拆开复杂句、段落围绕一个主题、变化句段长度。用于改稿节奏；不照搬英文段落字数上限。
- [市场监管总局：中华人民共和国广告法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)：重点参照第 4、8、11、14、17—19、28、38、46 条，约束虚假卖点、虚构引证/体验与广告识别。健康宣传须区分普通食品、保健食品等实际品类；换成模糊词不等于获得证据或宣传资格。具体内容保留人工合规审核。
- [小红书聚光：内容审核规则总则](https://ad.xiaohongshu.com/next_help/docs/8dc5bd9c45c9a90cb9912f3400d43f92)，页面更新时间 2026-03-23：强调事实与证明一致、引证可核验、素材与商品信息一致。这里是**聚光投放**规则，不扩大解释为全部自然笔记规则。核验时直接打开超时，通过搜索工具读取到官方页正文。

## 用户参考材料怎样被采用

用户提供了一份题为“TRAE 官方小红书爆款 Skill”的文本。作者身份、原始链接和许可未独立确认，因此不将原文收入仓库。吸收其“场景切入、整体主题一致、按表达形态写作、口语朗读改稿”的思路，用独立组织的方法和产品无关示例重新表达。

未采用：封面决定 80% 点击、35%—50% 流量来自搜索、埋词必然获得流量等无口径数据；强制“多用我”；统一字数/图片/标签限额；固定流量标签配方；功效词的所谓安全替代清单。没有依据不能写成平台事实或过审承诺。

用户提供的历史提示词与图片只用于比较构图、参考图角色、物件细节和视觉效果，没有作为对所有账户有效的增长实验。旧案例中的品牌、功效、数值和固定措辞不成为 Skill 的产品知识。

## 如何验证方法本身

文案：记录原稿/改稿及依据，由业务人员评估可用度和修改量。视觉：对照原参考检查约定的构图/风格维度，并看实际输出。增长：后续如需验证点击、收藏等变化，另行设计账户内对照测试；不能把编辑偏好、参数通过或离线测试解释成增长结果。
